Win Go Game Rules & Payouts
1. Round Lifecycle:

Each period has a fixed countdown (e.g. 60s or 30s). The final 5 seconds lock the round so no new bets can be submitted. The server then settles the round according to the winning number (0-9).

2. Colour Multipliers:
  • Green: If result is 1, 3, 7, 9 -> 2x payout. If 5 -> 1.5x payout.
  • Red: If result is 2, 4, 6, 8 -> 2x payout. If 0 -> 1.5x payout.
  • Violet: If result is 0 or 5 -> 4.5x payout.
3. Number Multipliers:

Choose exact number from 0 to 9. If your number hits, you win 9x payout!

4. Big / Small:
  • Big: Numbers 5, 6, 7, 8, 9 -> 2x payout.
  • Small: Numbers 0, 1, 2, 3, 4 -> 2x payout.
5. Service Fee:

A standard 2% handling fee is deducted on contract entry as specified in the Tiranga technical document.
